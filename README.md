# CEFR Practice Hub

เว็บฝึกภาษาอังกฤษที่รวมแบบฝึกจากชุดเอกสาร CEFR ใน Google Drive แยกเป็น A1–A2, B1–B2, Reading, Listening และ Level Up

## เนื้อหาในเว็บ

- **A1–A2** — 20 Sets รวม 300 ข้อ พร้อมเฉลยละเอียด คำแปล Sentence Map คำศัพท์ และ Learning Path
- **B1–B2** — 9 Sets รวม 134 ข้อจากไฟล์ Practice; Set 4 ในต้นฉบับและ KEY ข้ามหมายเลขข้อ 4 จึงคงตามเอกสาร
- **Reading** — 119 ข้อ/กิจกรรม จาก Reading Test 1–3
  - Test 1 และ Test 2 ตรวจด้วย Official KEY
  - Test 3 ไม่มี KEY ในโฟลเดอร์ จึงทำและบันทึกคำตอบได้ แต่ไม่เดาเฉลย
- **Listening** — 35 ข้อ พร้อมไฟล์เสียงต้นฉบับจาก Listening 1/2 PPTX
  - Listening 1 ไม่มี Official KEY ในโฟลเดอร์ จึงไม่ตัดสินถูก/ผิด
  - Listening 2 แยกป้ายเฉลยที่อนุมานจาก transcript ออกจาก Official KEY
- **Level Up** — 120 ข้อ/ช่อง จาก Focus on Form, Focus on Meaning และ Focus on Form and Meaning พร้อม KEY

> จำนวนรวมบนหมวดต่าง ๆ นับตามการปรากฏในแต่ละเอกสาร จึงตั้งใจเก็บโจทย์ที่ซ้ำกันไว้เมื่อโจทย์เดียวกันปรากฏในคนละชุดเอกสาร

## ฟีเจอร์การฝึก

ทุกหมวดหลักรองรับ:

- เลือกชุดข้อสอบและกลับมาทำต่อจากคำตอบเดิม
- สุ่มข้อสอบจากทุกชุดในหมวด โดยเก็บชุดสุ่มไว้ให้กลับมาทำต่อ
- ตรวจคำตอบเฉพาะข้อที่มี Official KEY หรือสถานะ transcript-derived ชัดเจน
- เฉลยแบบเรียนรู้: คำตอบของผู้เรียน, เฉลย, คำแปลโจทย์/ตัวเลือก/ประโยค, เหตุผล, Pattern, ทริก และ Sentence Map เมื่อเหมาะสม
- ปุ่มซ่อน/แสดงรายละเอียดเฉลย
- คลังคำศัพท์แยกตามหมวด พร้อมคำแปล ตัวอย่าง และตำแหน่งที่พบ
- Learning Path แยกตามเนื้อหาในแต่ละหมวด
- ทุกบทเรียนมีวิธีคิดทีละขั้น: โจทย์กำลังถามอะไร, คำสัญญาณ, ความหมายคำตอบ, ประโยคหลังเติม + คำแปล, เหตุผลที่เลือก, วิธีตัดตัวเลือก A–D, ส่วนเสริม/ศัพท์ที่ควรจำ
- หลังทำแบบทดสอบท้ายบท ระบบเปิดคำอธิบายละเอียดทุกข้อ แม้ตอบถูกก็ยังเห็นเหตุผลและการตัดตัวเลือก
- แบบทดสอบท้ายบทสุ่มจากโจทย์ต้นฉบับ เกณฑ์ผ่าน **80%** จึงปลดล็อกบทถัดไป
- บันทึกคำตอบ คะแนน ความคืบหน้าบทเรียน และกิจกรรมล่าสุดใน `localStorage`
- หน้าแรกมี **ทำต่อจากที่ค้างไว้** สำหรับกลับเข้าสู่กิจกรรมล่าสุด
- รองรับมือถือและเดสก์ท็อป

หมวด Listening เล่นไฟล์เสียงต้นฉบับจากหน้าเว็บได้ ส่วนชุดที่ไม่มี KEY ทางการจะไม่สร้างหรือเดาเฉลยขึ้นมาเอง

## คลังคำศัพท์

ข้อมูลคำศัพท์ของหมวดที่ขยายมาถูกสร้างจากข้อความในโจทย์/ตัวเลือก/บทอ่านจริง พร้อมคำแปลไทยเพื่อช่วยท่องจำ:

- B1–B2: 702 คำ/วลี
- Reading: 621 คำ/วลี
- Listening: 242 คำ/วลี
- Level Up: 474 คำ/วลี

คำแปลไทยเป็นสื่อช่วยเรียนตามบริบท ไม่ใช่ KEY ทางการของข้อสอบ

## โจทย์เสริมบทเรียน

คลังโจทย์เสริมเดิมยังเก็บไว้ใน `lesson-extra-questions.js` แต่ปัจจุบันปิดการใช้งานด้วย `LESSON_EXTRA_ENABLED = false` และไม่แสดงในบทเรียนหรือแบบทดสอบท้ายบท

## Login / Cloud progress

มี frontend สำหรับ Email/Password login และ progress sync ผ่าน Supabase แล้ว:

- `auth-sync.js` — Auth + sync logic
- `supabase-config.js` — Public Supabase URL / anon key
- `supabase/schema.sql` — ตาราง `user_progress` พร้อม Row Level Security ให้ผู้ใช้เข้าถึงเฉพาะข้อมูลของตัวเอง

หากยังไม่ได้ตั้งค่า Supabase เว็บจะทำงานใน **Guest mode** และเก็บข้อมูลเฉพาะ browser ตามเดิม ห้ามนำ Supabase `service_role` key ใส่ในไฟล์ frontend
