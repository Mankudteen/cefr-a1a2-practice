# CEFR A1–A2 Practice

เว็บฝึกภาษาอังกฤษระดับ A1–A2 สำหรับเรียน Grammar, ทำแบบฝึกหัด, ตรวจคำตอบ, ดูคำอธิบาย และติดตามความคืบหน้าในการเรียน

## ฟีเจอร์

- แบบฝึกหัด 20 Sets รวม 300 ข้อ
- สุ่มข้อสอบ 30 ข้อจากทุก Set
- ตรวจคำตอบพร้อมคำอธิบายภาษาไทย
- วิเคราะห์โครงสร้างประโยค S / V / O และชนิดคำ
- คลังคำศัพท์จากโจทย์
- ระบบบทเรียนแบบปลดล็อกตามลำดับ
- แบบทดสอบท้ายบท เกณฑ์ผ่าน 80%
- บันทึกคำตอบและความคืบหน้าใน `localStorage`
- รองรับมือถือและเดสก์ท็อป

## หมายเหตุ

คลังโจทย์เสริมสำหรับบทเรียนถูกเก็บไว้ใน `lesson-extra-questions.js` แต่ปัจจุบันปิดการใช้งานด้วย `LESSON_EXTRA_ENABLED = false` และไม่ได้แสดงในระบบเรียน/แบบทดสอบท้ายบท

## การรันในเครื่อง

เปิด `index.html` โดยตรง หรือรัน static server เช่น:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด `http://127.0.0.1:8000/`
